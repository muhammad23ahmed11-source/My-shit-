# Oak & Iron Training

A single-page website for a personal trainer in Camarillo, CA.

Open `index.html` in a browser, or host it on any static host (GitHub Pages, Netlify, Vercel).

## Before going live

- Replace the business name, phone `(805) 555-0142`, email, and studio address with real details.
- Replace the sample testimonials with real client quotes (with permission).
- Update prices, schedule, and certifications.
- The booking form currently builds a message the visitor can copy. To receive submissions directly, point it at a form service such as Formspree or Netlify Forms.
